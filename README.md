# Island of Ireland Games Industry Map

Interactive atlas of games-technology activity across Ireland and Northern Ireland: studios, publishers, education, services, events and adjacent sectors. Every entry is collected from a public source and links back to it.

Live map: https://rastaaashu.github.io/ireland-games-map/

Built for an MSc Data Analytics dissertation (DSA8030) with Medialab, Queen's University Belfast. The map is a single self-contained file generated by a reproducible open pipeline; data carries per-row provenance and personal data is held separately under consent rules.
