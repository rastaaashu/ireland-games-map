A database of games-technology activity across the island of Ireland: studios, publishers, education, services, events and adjacent sectors. Built for a QUB research project (DSA8030) at Medialab. Every entry comes from a public source and links back to it.

How it is made

Collect. Scrapers and research agents gather rows from public registries, directories, funding lists, storefronts and community sites. Raw pages are saved before any processing. Rate limits and robots.txt are respected. LinkedIn is never used.

Verify. Separate checking agents re-fetch sampled rows against their source pages. Claims a source does not support are corrected or removed, not guessed.

Process. Duplicates are merged across sources (registry beats directory beats storefront beats form). Locations use a free geocoding ladder: postcode, then street address, then town, then county centroid, with the confidence level saved per row. Street addresses come from each entity's own website.

Technology tags come from each entity's own collected text by keyword match. Nothing is added beyond what a source stated.

Publish. One pipeline command rebuilds this page, the CSV/GeoJSON exports and the data-quality report from raw data.

Town and county positions are approximate; the confidence level is shown on each record. Personal data from self-reports stays in a restricted store unless the person consented to display. County boundaries: GADM, academic use. This page is one self-contained file and works offline.
